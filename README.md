# 🥗 MyCalorie

> Türkiye'nin en kapsamlı yemek veritabanına sahip, tamamen ücretsiz ve internet bağlantısı gerektirmeyen kalori & makro takip uygulaması.

**🌐 Canlı Demo:** [itsravn.github.io/mycalorie](https://itsravn.github.io/mycalorie)

## ✨ Özellikler

- 🔍 **1000+ yemek veritabanı** — Kahvaltıdan fast food'a, sokak lezzetlerinden Türk tatlılarına her şey var
- ⚖️ **Canlı oran-orantı hesabı** — Porsiyonu değiştir, makrolar anında güncellenir
- 📊 **Günlük kalori & makro takibi** — Protein, karbonhidrat, yağ hedefleri
- 💧 **Su tüketimi takibi** — Günlük su hedefini takip et
- 📅 **Geçmiş görüntüleme** — Önceki günlerin kayıtlarına bak
- ⚖️ **Kilo geçmişi** — Tarih ve saatle birlikte kilo kayıtları, yanlış girişleri sil
- ✏️ **Manuel yemek ekleme** — Veritabanında olmayan yemekleri kendin ekle
- 🎯 **Özelleştirilebilir hedefler** — Kalori, protein, karbonhidrat, yağ ve su hedeflerini ayarla
- 📱 **PWA Desteği** — Telefona yükle, uygulama gibi kullan
- 🌙 **Dark Mode** — Göz yormayan koyu tema
- 💾 **Offline çalışır** — İnternet gerekmez, veriler cihazında saklanır

## 🚀 Kurulum & Geliştirme

```bash
# Repoyu klonla
git clone https://github.com/itsravn/mycalorie.git
cd mycalorie

# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Production build al
npm run build

# GitHub Pages'e deploy et
npm run deploy
```

## 🛠️ Kullanılan Teknolojiler

- **Vanilla JavaScript** — Framework bağımlılığı yok
- **Vite** — Hızlı geliştirme ve build
- **CSS Glassmorphism** — Modern koyu tema
- **Lucide Icons** — Temiz vektör ikonlar
- **LocalStorage** — Offline veri saklama
- **PWA** — Ana ekrana eklenebilir uygulama
